# Shortcut Keys

Shortcut keys are specific to a modelling language - any that are not re-defined inherit from the base language.

## DRAWING Short Cut keys

|Item | Key |
|-----|-----|
|box| <kbd>b</kbd>|
|ellipse| <kbd>e</kbd>|
|line| <kbd>l</kbd>|
|magnet| <kbd>F1</kbd>|
|pointer| <kbd>Escape</kbd>|
|image| None|
|metadata| None|
